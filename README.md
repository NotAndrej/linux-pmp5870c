Mainline Linux kernel fork targeting the Prestigio PMP5870C (RK3066).

Based on archeYR's bq-curie branch. The PMP5870C uses:
| Component | Status |
|-----------|--------|
| Display 1280x800 | Works* |
| BYD BF6932 touch | No driver yet |
| ES8323 audio | Mainline |
| BMA222E accel | Mainline |
| RTL8188EU wifi | Mainline |
| RK903 bluetooth | Mainline |

Manufacturer refused to provide GPL source. We did it anyway.
